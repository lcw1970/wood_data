# 두 종류 선택형 참고 계산 (2026-10-28)

사용자 요청에 따라 골지름·제품·선공·각도·비중의 입력 항목을 추가하지 않는다. 기존 밀도·직경·목재 종류에 스크류/다월 선택만 추가한다. 기본 선택은 스크류다.

## 적용 방식

- 스크류: EC5/NDS/KDS 세 기준의 평행/직각 예측값을 표시한다. 비교 가정은 선공, 축-섬유 각도 90°, 입력 d = 평활부 지름 = 나사산 외경, 평활부 관입 ≥4d, 나사산 지압 길이 ≤ 전체의 1/4이다. 실제 시공과 형상을 확인한 값이 아니므로 제품별 STS 설계값으로 제시하지 않는다. KDS는 일반 STS 규정으로 확대하지 않고 래그나사못 규정임을 명시한다. 이 가정에서 d>6 mm는 다월과 같은 수치가 나올 수 있다.
  - EC5: EN 1995-1-1:2004+A1:2008 §8.7.1(2)/(4)/(5). d>6 mm는 §8.5.1.1 식(8.31)~(8.33), d≤6 mm는 §8.3.1.1 식(8.16)의 선공 못 규정을 사용하여 방향 공통값. 원문 PDF: https://rk-hub.hope-erasmusproject.eu/index.php/ro/item/download/197_ac9b30e923d9e2a58ac15e37f6521aca
  - NDS: NDS 2018 §12.3.3 Table 12.3.3 및 주석을 SI로 환산. 원문(psi, D inch)은 대직경 11200G / (6100G^1.45/√D), 소직경 16600G^1.84. §12.3.7 지름 정의 및 평활부 사용 조건을 가정. https://awc.org/wp-content/uploads/2021/10/AWC_NDS2018-withCommentary_20210928_AWCWebsite_Chapter12.pdf
  - KDS: KDS 41 50 30:2022 §4.7.3.1에서 79G / (216G^1.45/√d). d는 나삿니 없는 못대 지름. 표 4.7-1 규격에 맞는 래그나사못 규정이다. 공식 원문 HWPX: https://standard.go.kr/KSCI/newSta/common/dbFileDown.do?atchmnflId=APOT2025011613323428&atchmnflSn=70 ; 공식 배포 페이지: https://standard.go.kr/KSCI/technologyIntro/getTechnologyDetailView.do?trgId=0000000026&trgReformNo=0006
- 스크류 문헌식은 별도 예측 카드로 보존한다. Cabrera 외(2022), Forests 13, 1154, Table 3(PDF p.10)의 prEC5 비교 모델에서 ε=90°를 고정: `0.019 × ρ^1.24 × d^-0.3`. 평행/직각을 나누지 않는 문헌 기반 예측값이며 실측값이나 위 EC5 채택 규정과 동일시하지 않는다. https://doi.org/10.3390/f13081154
- 다월: 평활 강재 및 볼트 평활부를 대상으로 한 EC5형·NDS형·KDS 장부촉 참고식을 표시한다. EC5 k90는 HARDWOOD에 0.90+0.015d, 나머지에 침엽수 가정 1.35+0.015d를 쓴다. G는 별도 입력 없이 ρ/1000 가정값임을 표시한다. KDS 계수는 확인된 79/216으로 수정한다. NDS는 6.35 mm 미만에서 114.453G^1.84를 양 방향에 사용한다. 목재 다월 모델은 아니다.
- 입력 밀도는 평균/특성/함수율 기준이 확정되지 않은 사용자 입력이므로 모든 지압 출력은 ‘참고값’으로 표시한다. GLT/CLT에 대한 다월 계산은 침엽수 평활부 가정이며 교차층 구성은 별도 모델링하지 않는다.
- 앱 입력 범위는 0<d≤30 mm로 제한한다. 이는 프로그램의 입력 범위이며 모든 재료/제품에서 식의 유효성을 검증한 범위를 의미하지 않는다.
- 기존의 임의 표준편차(예측×15%), 그로부터 만든 5% 하한치 및 이를 사용한 내부 UTM 판정 계산은 제거했다. 압축강도 밀도 비례 추정식은 이번 변경 대상에서 제외하며 기존 참고식으로 표시한다.

## 논문 비교

CSV에 fastenerType 메타데이터를 추가했다. 기존 25개 원문 미대조 행은 종류를 추정하지 않았다. 대조한 41개 행은 원문 시험에 따라 SCREW / DOWEL로 분류했다. DOWEL 그룹에는 강봉 다월 및 볼트 평활부 시험을 포함하며 카드에 이를 표시한다.

- paper-9: T1/T2 스크류; T3/T4 볼트.
- paper-30: 볼트 평활부.
- paper-34: 강봉 다월.
- paper-72: STS 스크류.

논문 필터는 선택 종류를 먼저 적용하고 기존 목재 분류/제품 형태 및 밀도 10%·직경 1 mm 범위를 적용한다. 원문에서의 실측/공칭 직경과 면적 기준은 카드의 시험 조건에 보존한다. 종류 일치가 시험 정의까지 일치한다는 뜻은 아니다.

## 구현

계산식은 EmbedmentPredictionService 한 곳에서 평가한다. 브라우저는 서버가 제공한 곡선 데이터를 표시하며 별도 수식을 중복 구현하지 않는다. 세 기준 및 별도 문헌값, EC5 스크류 6 mm와 NDS 6.35 mm 분기, 수정 계수, 그래프·결과 일치, 원문 출처 및 종류별 논문 격리를 테스트했다. 두 종류 모두 그래프 두 개에 세 기준을 표시한다. 분기 부근 샘플을 추가해 경계 사이를 단순 보간하지 않게 했다.

기존 fastener_calculation_plan.md의 상세 입력안보다 이 문서의 사용자 요청에 따른 단순화가 우선한다. 과거 calculation_review.md는 변경 전 감사 기록으로 보존한다.

## 그래프의 실측 점과 확대 표시 (2026-10-28)

- 세로축은 예측선과 표시 중인 실측값 전체 범위에서 위아래 여백을 확보해 자동 확대한다. ‘세로축 0부터 보기’ 버튼으로 기준선을 0으로 되돌릴 수 있으며, 상단 여백은 유지한다. 가로축 끝점에도 마커 여백을 둔다.
- 아래 근접 시험 및 조건이 다른 참고 논문 카드에 표시한 시험만 같은 그래프에 별도의 산점도로 표시한다. ◆는 근접 조건, △는 밀도가 다르거나 미기재인 조건이다. 논문의 원래 직경과 강도를 사용하며 입력 밀도로 환산하지 않는다. 실측 점을 연결하거나 예측선에 포함하지 않는다.
- 평행·직각 단일 수치만 사용하며 R/T가 보고된 경우 각각 독립 점으로 표시한다. 범위값, 미수록값을 평균내거나 0으로 대체하지 않는다. 표준편차는 생성하지 않는다.
- 툴팁에 수종, 논문 밀도(또는 미기재), 직경, R/T 방향, 시험법, 논문명·표 위치·DOI를 표시한다. 점을 클릭하면 해당 카드로 스크롤하고 키보드 초점을 맞춘다. 종류별 논문 필터와 카드의 원문 값은 그대로 유지한다.

## 적용식 경계의 선 연결 수정 (2026-10-28)

NDS 6.35 mm 전후와 EC5 스크류 직각방향 6 mm 전후는 서로 다른 식을 사용한다. 경계 양쪽 점을 직선으로 연결하면 계산하지 않은 중간 강도를 나타내는 수직선이 생기므로 null 구분점을 넣고 `spanGaps: false`로 분리한다. null은 축 범위 산정에서 제외하며 강도 0으로 취급하지 않는다. 경계에 입력한 직경의 실제 계산값은 그대로 보존한다.

가로축은 2 mm 단위의 정수 경계를 사용한다. 5.6·24.4처럼 마커 여백에서 발생한 눈금을 없애고, 마커 클리핑을 해제하여 끝점도 보이게 한다. 논문 실측 점의 실제 직경(예: 12.2 mm)은 입력 직경(예: 12 mm)으로 옮기지 않는다.
