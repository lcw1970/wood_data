## 입력 및 해석 규칙

- 새 열 `sourceId`, `sourceTitle`, `sourceLocation`, `testConditions`로 출처와 시험 조건을 보존한다. 기존 행은 이 열을 비워 두고 화면에서 ‘기존 등록’으로 구분한다. 기존 25개 값과 출처를 이번 작업에서 재검증한 것은 아니다.
- 실험 평균, 항복값, 특성값, 설계값을 같은 의미로 취급하지 않는다. 추가 항목은 표에 제시된 평균 또는 평균 항복값이다. 범위로 변환하거나 서로 다른 평가법의 값을 합치지 않았다.
- paper-9는 EN 383 평가값만 사용했다. 같은 시험의 ASTM 및 EN 408 재평가값은 중복 등록하지 않았다. 시험군별 평균 밀도를 각각 보존한다. 9 mm 스크류는 공칭 직경이며 강도 산정에 사용된 유효 직경 6.5 mm를 조건에 명시한다.
- paper-30은 Table 3의 fh_y를 사용한다. fh_u는 등록하지 않았다. 30°·45°·60° 결과는 평행/직각 열에 넣지 않았다. 밀도 466 kg/m³는 전체 재료 평균이다. 직각값이 없는 시험 조건은 `-`로 표시한다.
- paper-34는 실측 다월 직경을 사용하고 공칭 직경을 조건에 기록한다. 양 방향을 합친 `Both` 및 직경 전체 평균 `All`은 중복 등록하지 않았다.
- paper-72는 Table 4의 Type 1과 혼합하지 않고 Table 5의 Type 2 값만 사용했다. `R x; T y`는 두 방향의 개별 평균으로 범위가 아니다. T-series는 나사산부, S-series는 평활부이다. 시험 재료는 원목 시험편이며 CLT 데이터로 분류하지 않았다. 적용 시험법은 KS F 2156:2022이다.
- paper-34와 paper-72에서 비중 G만 보고된 경우 이를 kg/m³ 밀도로 임의 환산하지 않고 밀도는 `-`로 남겼다. 비중은 시험 조건에 기록한다.
- CSV는 현재 로더가 쉼표로 분리하므로 셀 내부 쉼표 및 줄바꿈을 사용하지 않는다. 새 열은 뒤에 추가해 기존 8개 열 순서를 보존했다.

## 예측값과 논문 실측값 분리

- 예측 그래프의 고정 실험값 및 근거 없는 오차막대를 제거했다. 그래프에는 기존 EC5/NDS/KDS 구현식의 예측곡선과 입력 직경의 각 예측값만 표시한다. 서로 다른 식의 평균을 대표 예측값으로 표시하지 않는다.
- 별도 논문 비교 영역은 원문 대조한 4편의 항목만 사용한다. 기존 25개 항목은 전체 DB에 보존하되 검증된 논문 비교 후보에는 넣지 않는다.
- 같은 목재 분류·제품 형태(침엽수 원목 / 활엽수 원목 / 집성재 / CLT)를 먼저 구분한다. 집성재와 원목, 집성재와 CLT는 서로 대체하지 않는다. 이는 수종 동일성을 보장하는 조건은 아니다.
- ‘밀도·직경이 가까운 시험’의 기본 검색 범위는 입력 밀도 대비 밀도 차이 10% 이내 및 직경 차이 1 mm 이내이다. 이는 검색 범위이며 통계적 신뢰도나 강도 예측 정확도가 아니다. 최대 8개 시험을 표시한다.
- 동일 분류·제품 형태이고 직경 차이 1 mm 이내지만 밀도가 범위를 벗어나거나 미기재인 항목은 ‘조건이 다른 참고 논문’으로 최대 4개 표시한다. 입력 조건의 실험값으로 취급하지 않는다. 미기재 밀도를 비중으로 대체하지 않는다.
- 밀도/직경의 단일 수치가 확인되는 항목만 수치 비교한다. 범위의 중앙값을 실측값으로 만들어내지 않는다. 카드에 원래 강도값·밀도·직경·입력과의 차이·시험법·강도 정의·논문 제목·DOI·표 및 페이지를 표시한다. 논문값을 입력 밀도에 맞춰 보정하거나 회귀하지 않는다.
- 기준에 맞는 원문 대조 자료가 없으면 ‘가까운 시험 없음’으로 표시한다. 원문에 없는 표준편차·오차막대·평균값을 생성하지 않는다.
- 예측식 계수와 내부의 가정식 자체를 논문 데이터로 재보정한 것은 아니다. 이 변경은 출처 없는 실험값 표시를 제거하고 비교 대상을 명확히 구분하는 작업이다.

## 2026-10-28 파스너 종류 분류

추가 열 `fastenerType`은 원문 대조한 시험에만 SCREW / DOWEL로 기록한다. DOWEL은 볼트 평활부를 포함하며, 기존 원문 미대조 25개 행은 비워 둔다. 숫자는 변경하지 않았다. 종류 선택에 따른 계산 및 논문 필터는 `simplified_fastener_model.md`를 따른다.

## Full-hole/Half-hole 및 강도 정의 (2026-10-28)

CSV 뒤에 `testSetup`과 `strengthBasis`를 추가했다. 원문 시험 형상과 강도 산정법을 대조한 41개 행에 기록하고 기존 25개 미대조 행은 UNKNOWN으로 유지한다. paper-9/30은 Full-hole, paper-34/72는 Half-hole이다. paper-9는 EN 383 최대값, 나머지 세 논문은 5% 직경 오프셋 항복값이다. 기록 위치는 `paper_sources.json`의 `testMetadataLocation`에 보존한다. 원래 밀도·직경·강도 값은 변경하지 않았다.
