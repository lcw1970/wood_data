# 탐색 화면 수종 표시명

CSV의 `species_scientific`은 원문 수종 식별값으로 그대로 보존한다. 화면의 한글명은 검색·선택을 돕는 표시명이며 모든 이름이 국가 표준명이라는 뜻은 아니다. 일반적으로 쓰는 이름과 음역을 함께 사용한다. 영어 보통명 slash pine은 ‘슬래시소나무’, Eucalyptus saligna는 ‘유칼립투스 살리그나’로 표기한다.

| CSV 학명 | 화면 한글명 |
| --- | --- |
| Betula spp. | 자작나무속·종 미상 |
| Chamaecyparis obtusa | 편백 |
| Cryptomeria japonica | 삼나무 |
| Eucalyptus saligna | 유칼립투스 살리그나 |
| Fagus sylvatica | 유럽너도밤나무 |
| Larix kaempferi | 낙엽송 |
| Picea abies | 독일가문비 |
| Picea spp. | 가문비나무속·종 미상 |
| Picea spp.; Pinus spp.; Abies spp. (SPF) | SPF 혼합 수종군 |
| Pinus caribaea x Pinus elliottii | 카리브소나무 × 슬래시소나무 교잡종 |
| Pinus elliottii | 슬래시소나무 |
| Pinus koraiensis | 잣나무 |
| Pinus radiata | 라디아타소나무 |
| Pinus sylvestris | 구주소나무 |
| Pinus sylvestris var. mongolica | 백두산소나무 |
| Pinus taeda | 테다소나무 |
| Populus x euroamericana | 이태리포플러 |
| Pseudotsuga menziesii | 더글러스퍼 |
| Quercus spp. | 참나무속·종 미상 |

`spp.` 자료를 특정 종으로 치환하지 않는다. SPF는 세 속의 혼합군으로 표시하며 단일 수종과 합치지 않는다. 변종과 교잡종도 CSV의 별도 식별값을 유지한다. 화면에서만 교잡 기호 `x`를 `×`로 표시하고, SPF의 세 속은 `/`로 구분한다.

이름 확인에 참고한 자료:

- [국립생물자원관 관속식물 목록](https://www.nibr.go.kr/aiibook/catImage/26/Vascular%20Plants.pdf): Pinus koraiensis, Pinus sylvestris 및 var. mongolica의 한글명.
- [국가기술표준원 수종명 자료](https://www.kats.go.kr/download.do?filename=18613_201605250925186150.pdf): Picea abies, Cryptomeria japonica, Fagus sylvatica의 한글명.
- [국립산림과학원 포플러 단벌기 목재에너지림 자료](https://book.nifos.go.kr/art.do/10110/contents/5810867): 이태리포플러 표기.
- [멜버른대학교 다국어 식물명 자료](https://www.plantnames.unimelb.edu.au/Sorting/Pinus.html): Pinus elliottii의 영어 보통명 slash pine.
