## 데이터와 표시

- 17편의 186개 시험 조건에서 평행 129개, 직각 99개(이 중 R 15개, T 15개)를 합쳐 강도값 228개를 표시한다. 침엽수 계열 198개, 활엽수 30개다. 228개는 개별 시편 수가 아니다.
- 초기 표시는 섬유 평행이다. 방향·파스너·시험 형상·강도 정의·제품·수종을 필터링한다. 모든 방향을 선택하면 R/T 및 일반 직각값을 각각 표시한다.
- 수종 선택은 논문 제목 대신 CSV의 `species_scientific`으로 묶어 `학명(한글명)`을 표시한다. 19개 수종·수종군 중 선택한 목재 분류의 목록을 알파벳순으로 제공한다. 같은 수종의 다른 논문·시험군은 함께 보이며 시험 조건과 출처는 각 점·표·상세에 보존된다. 분류를 바꾸면 해당 분류에 없는 수종 선택은 ‘전체 수종’으로 돌아간다. SPF 혼합군, 속 수준 자료, 변종과 교잡종은 별도 항목이다. 표시명과 참고자료는 [수종 이름 안내](species_names.md)를 참조한다.
- 상단 필터에서 ‘목재 분류’로 침엽수 또는 활엽수를 먼저 고른 다음, 바로 옆의 ‘수종’에서 학명(한글명)을 선택한다. 좁은 화면에서는 같은 순서로 위아래에 배치한다. 그래프에는 별도 분류 선택란을 두지 않는다. 선택한 분류의 산점도 하나를 전체 너비로 표시하고 통계·분포·데이터 표도 같은 분류로 갱신한다. 축 범위는 선택한 데이터에 맞춘다. 기본은 침엽수이며 필터 초기화 시 돌아간다. 색은 수종, 점 모양은 FH 원 / HH 삼각형 / 미확인 마름모다. GLT와 원목은 제품 필터로 분리할 수 있다.
- ‘모든 방향’에서는 회전 가능한 3D 산점도를 기본으로 표시한다. X=실제 직경, Y=보고 강도, Z=평행 / 직각(R·T 미구분) / R / T의 네 범주다. 일반 직각층에 R/T를 중복 추가하지 않는다. 방향별 개수를 함께 표시하며 빈 층도 0개로 유지한다. 층 간격은 수치적 의미가 없다. 범주만 Z에 배치하고 보고 직경·강도에 흔들림이나 보정을 적용하지 않는다.
- 3D는 드래그·방향키·좌우 회전 버튼으로 회전하고 +/− 버튼이나 키로 확대·축소한다. ‘시점 초기화’와 Home 키로 기본 시점으로 돌아온다. 모든 방향일 때 ‘2D 겹쳐 보기’로 비교할 수 있다. 단일 방향과 ‘섬유 직각 전체’는 기존 2D를 사용한다. 필터·테마 변경은 현재 시점을 유지하고 전체 필터 초기화는 시점과 보기 모드도 초기화한다. Canvas 정사영 렌더러를 사용해 추가 외부 라이브러리나 WebGL 의존성 없이 작동한다. 보기 전환 시 입력 이벤트와 크기 관찰자를 해제한다.
- 원문 실제/공칭 직경과 강도를 그대로 사용하고 중복 좌표에 임의 흔들림을 주지 않는다. 미수록 강도·범위값·미기재 밀도를 변환하지 않는다.
- 히스토그램은 현재 필터의 논문 보고값을 10 MPa 구간(하한 포함·상한 미포함)으로 집계한다. 개별 시편의 확률분포·오차범위·정규성으로 해석하지 않는다.
- 산점도 점을 누르면 수종, 시험 형상, 강도 정의, 밀도, 시험 조건, 논문과 표 위치를 확인한다. 같은 좌표의 점은 상세에 함께 표시한다. 데이터 표에서도 같은 상세를 열 수 있다.

검증: 기존 계산 및 논문 필터 회귀 테스트, 186/228/17/25 건수, 19개 CSV 수종 식별값 전달, 여러 논문의 같은 수종 선택, FH/HH와 강도 정의, R/T 및 미기재 값 보존, 필터 조합·빈 결과·히스토그램 합계를 확인한다.

3D 검증: 네 방향의 상호 배타적 배치, 회전 시 기하 보존, 시점·확대 범위, 겹친 점 전체 선택, 드래그와 클릭 구분, 키보드 초기화와 이벤트 정리를 자동 검사한다. 로컬 브라우저에서 실제 드래그·확대·초기화·2D 전환·단일 방향·활엽수·빈 결과·밝은/어두운 테마와 원문 상세를 확인했다.

## 공통 CSV 연동

현재 페이지는 `exports/literature_strength_long.csv`의 검토한 시험군 평균을 사용한다. 새 논문 ID를 Java 코드에 등록할 필요가 없다. 검증 후 CSV에 행을 추가하면 다음 새로고침에서 수종 필터·산점도·히스토그램·계산기 비교에 반영된다. 새 수종은 학명으로 자동 추가되며 한글 표시명이 없으면 ‘한글명 미등록’으로 표시한다. 기존 넓은 CSV의 미대조 25개만 따로 보존한다. 전체 CSV 다운로드는 `/literature.csv`이다. 추가·검증 명령은 README의 논문 추가 절차를 따른다.
