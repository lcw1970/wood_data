# 논문 데이터 탐색 · 시험용 (2026-10-28)

계산기 입력은 유지한다. 논문 시험 형상과 강도 평가 방식을 CSV 메타데이터로 추가하고 카드·툴팁·목록에 표시한다. 원문 대조 자료 전체는 별도 `/explorer` 페이지에서 탐색한다.

논문 파일 식별자·SHA-256·원문 주소는 `paper_sources.json`에 보존한다. 시험 형상은 표준 이름에서 추정하지 않고 해당 논문 형상을 확인했다. 기존 미대조 25개 행은 UNKNOWN으로 유지하고 탐색 산점도에서 제외한다.

CSV의 기존 13개 필드는 그대로 두고 testSetup/strengthBasis 두 열을 추가했다. 과거 13필드 DTO 생성은 UNKNOWN을 기본값으로 받아들이며 기존 비교 필터의 파스너·목재 제품 격리를 유지한다. 형상 간 환산계수나 임의 강도 보정은 도입하지 않는다.

## 데이터와 표시

- 45개 시험 조건에서 평행 41개, 직각 46개(이 중 R 15개, T 15개)를 합쳐 강도값 87개를 표시한다. 침엽수 계열 79개, 활엽수 8개다. 87개는 개별 시편 수가 아니다.
- 초기 표시는 섬유 평행이다. 방향·파스너·시험 형상·강도 정의·제품·논문을 필터링한다. 모든 방향을 선택하면 R/T 및 일반 직각값을 각각 표시한다.
- 침엽수와 활엽수는 서로 다른 그래프에 같은 축 범위로 표시한다. 색은 수종, 점 모양은 FH 원 / HH 삼각형 / 미확인 마름모다. GLT와 원목은 제품 필터로 분리할 수 있다.
- 원문 실제/공칭 직경과 강도를 그대로 사용하고 중복 좌표에 임의 흔들림을 주지 않는다. 미수록 강도·범위값·미기재 밀도를 변환하지 않는다.
- 히스토그램은 현재 필터의 논문 보고값을 10 MPa 구간(하한 포함·상한 미포함)으로 집계한다. 개별 시편의 확률분포·오차범위·정규성으로 해석하지 않는다.
- 산점도 점을 누르면 수종, 시험 형상, 강도 정의, 밀도, 시험 조건, 논문과 표 위치를 확인한다. 같은 좌표의 점은 상세에 함께 표시한다. 데이터 표에서도 같은 상세를 열 수 있다.

검증: 기존 계산 및 논문 필터 회귀 테스트, 45/87/5/25 건수, FH/HH와 강도 정의, R/T 및 미기재 값 보존, 필터 조합·빈 결과·히스토그램 합계를 확인한다.

## 공통 CSV 연동

현재 페이지는 `exports/literature_strength_long.csv`의 검토한 시험군 평균을 사용한다. 새 논문 ID를 Java 코드에 등록할 필요가 없다. 검증 후 CSV에 행을 추가하면 다음 새로고침에서 논문 필터·산점도·히스토그램·계산기 비교에 반영된다. 기존 넓은 CSV의 미대조 25개만 따로 보존한다. 전체 CSV 다운로드는 `/literature.csv`이다. 추가·검증 명령은 README의 논문 추가 절차를 따른다.
