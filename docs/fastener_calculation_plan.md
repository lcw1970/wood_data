# 스크류 / 다월 선택을 위한 계산 수정안

검토일: 2026-10-28. 대상은 목재에 횡하중을 전달하는 금속 파스너의 지압강도다. 화면 상위 선택은 ‘스크류’와 ‘다월(평활 강재)’ 두 가지로 두고, 필요한 형상 입력만 선택에 따라 펼친다. 이 문서는 구현안이며 계산기 소스는 이번 조사에서 변경하지 않았다.

## 입력 화면

| 항목 | 다월 | 스크류 |
| --- | --- | --- |
| 지름 | 실제 평활 강봉 지름 d | 공칭 외경 d_out과 나사골 지름 d_root를 구분 |
| 평활부 정보 | 해당 없음 | 지압 구간이 나사부인지 평활부인지; 일반 EC5 적용 시 필요한 관입 길이 |
| 설치 | 구멍/하중 조건 | 선공 여부 및 제품에서 요구하는 선공 조건 |
| 방향 | 하중-섬유 각도 α; 우선 0°/90° | 하중-섬유 각도 α와 스크류 축-섬유 각도 ε를 구분 |
| 제품 | 평활 강재 다월; 목재 다월 제외 | 일반 규정 모드 또는 확인된 제품 평가서 프로필 |
| 목재 | 수종군과 제품 형태를 분리 | 동일 |
| 밀도 | 평균/특성밀도 및 측정 기준 | 동일 |
| 비중 G | NDS/KDS를 사용할 때 독립 입력 | 동일; 밀도/1000 자동 환산 제거 |

스크류도 제품이 특정되지 않았다면 일반 규정 적용 조건을 확인하는 입력을 제공한다. 특정 제품 프로필이 있으면 외경·골지름 등의 값을 제조사 자료에서 채우되 사용자가 확인할 수 있게 한다. 특정 제품의 식을 모든 스크류에 적용하지 않는다.

## 계산 분기

### 1. 다월

현재 EC5 식에 해당하는 EN 1995-1-1:2004+A1:2008 계열의 기본 형태는 다음과 같다.

- f_h,0,k = 0.082 × (1 - 0.01d) × ρ_k
- f_h,α,k = f_h,0,k / (k90 × sin²α + cos²α)
- k90는 침엽수 1.35 + 0.015d, 일반 활엽수 0.90 + 0.015d, LVL 1.30 + 0.015d 등 해당 재료 규정을 따른다.

다월 규정의 지름 범위를 포함해 적용 조건을 확인한다. 평균밀도 대입 결과와 특성밀도에 따른 특성강도를 구분한다. 판본과 적용 조항을 결과에 표시한다.

### 2. 스크류 - 일반 규정

같은 판본 §8.7.1에서는 나사부 영향을 유효직경으로 고려한다. 규정의 조건을 만족하는 평활부가 있으면 평활부 지름, 그렇지 않은 경우 일반적으로 1.1 × 나사골 지름에 따른 규정을 검토한다. 평활부 스크류는 6 mm 경계에서 볼트/못 규정을 참조한다. 따라서 종류 선택만으로 임의의 감소계수를 곱하지 않고 조건에 맞는 식과 지름을 결정한다.

### 3. 스크류 - 제품 평가서

예를 들어 DIBt ETA-12/0062의 SFS WR은 외경 사용과 선공/축 방향에 따른 별도 식을 지정한다. 이 식은 해당 제품 범위와 재료/설치 조건에만 적용한다. 일반 EC5 유효직경 규칙과 제품 평가서의 외경 사용 규칙을 섞지 않는다. 필요한 정보가 없으면 해당 모델의 값 대신 ‘적용 조건 확인 필요’를 표시한다.

두 선택의 결과가 반드시 달라야 하는 것은 아니다. 조건에 따라 식을 공유할 수 있으며, 이때 차이는 사용 지름과 적용 범위에 있다. 제품별 식에는 방향의 정의도 다를 수 있으므로 모든 출력을 무조건 평행/직각 2개 숫자로 복제하지 않는다.

### 4. NDS/KDS

- NDS의 큰 직경용 약 77.2G 및 212G^1.45/√d는 단위 환산상 타당하다. 작은 직경 분기, 규정의 지름 정의 및 파스너 범위를 따로 적용한다.
- KDS의 확인된 볼트/래그나사못 조항에 맞추어 68.3/180 계수는 79/216으로 교정한다. 이 조항을 모든 셀프태핑 스크류용 검증식으로 표시하지 않는다.
- 필요한 G나 파스너 적용 근거가 없으면 특정 기준의 값을 확정하지 않는다. 사용할 수 있는 모델만 표시한다.

## 결과 및 논문 비교

1. 예측값에는 모델명·판본·지름 기준·밀도/비중 기준과 평균 대입 참고값 또는 특성값의 구분을 표시한다.
2. 원문 근거가 없는 SD=예측×15%, 그로부터 만든 ‘5% 하한치’, 서로 다른 기준의 평균은 제거한다. 압축강도 모델은 독립 검토한다.
3. 논문 데이터에 파스너 종류, 제품명, 직경 기준, 선공, 면적 기준, 강도 정의를 별도 필드로 기록한다. 과거 문자열을 추정 파싱하여 종류를 결정하지 않는다.
4. ‘같은 종류의 근접 시험’은 목재 분류/제품 형태와 더불어 파스너 종류·지름 기준도 확인한다. 지름 기준이 다르면 차이를 명시하고 별도 참고 자료로 분리한다.
5. 다월 선택에서 스크류 시험, 스크류 선택에서 다월 시험을 근접 실험값으로 제시하지 않는다. 밀도 미기재 처리와 실제 논문값 보존은 유지한다.

## 구현과 검증 순서

1. `FastenerType`과 형상·밀도 기준을 담은 입력 모델을 만든다. 첫 화면에서 종류를 명시적으로 선택하게 한다.
2. 계산을 컨트롤러/JS의 중복 수식에서 별도 계산 서비스로 옮긴다. 그래프도 동일한 계산 결과를 받아 서버와 브라우저 결과가 달라지는 일을 방지한다.
3. 확정한 다월 규정과 일반 EC5 스크류 규정부터 지원하고, 제품 프로필은 원문 확인된 것부터 추가한다.
4. 논문 비교 데이터의 파스너 메타데이터를 정리한 뒤 종류별 필터를 적용한다.
5. 지름 분기 경계, 밀도와 G의 독립성, 나사골/외경 혼동, 평활부 조건, 선공/방향, 지원 범위 밖 입력, 그래프-수치 일치, 논문 종류 혼합 방지를 회귀 테스트한다.
